# EPHI_SentinelSites_DR_project

Sentinel-based Molecular Surveillance of Plasmodium falciparum Artemisinin Resistance Mutations in Ethiopia

This repository contains all the necessary data and scripts to generate the figures and calculate prevalence rates for the manuscript titled “Rising Prevalence of Plasmodium falciparum Artemisinin Resistance Mutations Across Ethiopia.” It includes plots featured in both the main text and supplementary materials of the manuscript. Additionally, useful software packages and tools for working with MIP data can be found at  https://github.com/bailey-lab/MIPTools and https://github.com/Mrc-ide/mipanalyzer. For calculating complexity of infection and population allele frequencies using SNPs available at https://github.com/OJWatson/McCOILR.
